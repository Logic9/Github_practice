# Little Endian Detector

정수가 메모리에 놓이는 바이트 순서를 관찰하고 리틀 엔디언 여부를 확인하는 학습 예제입니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `LittleEndian_Detector.c` | 정수 `0x00FF`의 하위 바이트를 읽어 엔디언을 판별하고 결과 출력 |
| `ReadMe.pdf` | 기존에 포함된 실습 참고 문서 |

`Test_Little_Endian()`은 정수의 주소를 `unsigned char *`로 해석하여 첫 바이트가 `0xFF`인지 확인합니다. `main()`은 판별 결과를 콘솔에 출력한 뒤 Enter 입력을 기다립니다.

## 빌드와 실행

C 컴파일러가 있는 환경에서 저장소 루트 기준으로 실행합니다.

```sh
cc -Wall -Wextra LittleEndian_Detector.c -o endian-detector
./endian-detector
```

컴파일 결과물은 저장소에 포함할 필요가 없습니다. 별도 라이브러리나 환경 변수는 사용하지 않습니다.

## 현재 코드의 한계

바이트 출력 루프의 주소 표시는 `&num + i`를 사용하지만 실제 값은 `(unsigned char *)&num + i`에서 읽습니다. 정수 포인터와 바이트 포인터의 이동 폭이 달라 두 번째 줄의 주소 표시는 출력 바이트의 실제 위치와 일치하지 않습니다. 최종 엔디언 판별은 별도의 첫 바이트 비교로 수행됩니다.

이 프로그램은 일반적인 리틀/빅 엔디언 관찰용 예제입니다. 특수 바이트 순서나 모든 하드웨어 구조를 분류하는 진단 도구로 검증된 것은 아닙니다.
